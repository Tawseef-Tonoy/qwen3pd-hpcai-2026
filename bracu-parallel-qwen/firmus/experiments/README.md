# Experiment Naming

Basic examples:

    BASIC-REF07-001
    BASIC-CANDIDATE-001
    BASIC-OFFICIAL-001

Bonus examples:

    BONUS-CONC-001
    BONUS-NIXL-001
    BONUS-NET-001
    BONUS-PD-001
    BONUS-TP-001
    BONUS-NUMA-001

Each experiment should record:

    purpose
    hypothesis
    baseline
    single controlled change
    script hash
    Slurm job ID
    resource shape
    configuration
    expected result
    measured result
    interpretation
    status
